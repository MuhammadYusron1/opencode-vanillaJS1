# Pixel & Co - Creative Agency

## Quick Reference
- **Type:** Plain HTML/CSS/JS landing page
- **Colors:** #DF301C (red), #FF9100 (orange), #FFF1D1 (cream), #00B7CD (teal)
- **Font:** Inter (Google Fonts)
- **Theme:** Dark background (#1a1a2e), cream sections

## File Structure
├── index.html        # Home (hero, services, testimonials)
├── work.html         # Portfolio grid
├── contact.html      # Contact form
├── css/style.css     # All styles
└── js/main.js        # All JavaScript

## Code Rules
- Semantic HTML5 (header, main, section, footer)
- BEM CSS naming (.block__element--modifier)
- ES6+ JS (const/let, arrow functions, template literals)
- Mobile-first responsive design
- No frameworks - vanilla only

## Design Tokens
--color-primary: #DF301C;
--color-secondary: #FF9100;
--color-light: #FFF1D1;
--color-accent: #00B7CD;
--color-dark: #1a1a2e;
--color-text: #333333;

## Workflow Rules (IMPORTANT!)
**User writes ALL code manually - AI only guides!**

How this project works:
- AI explains WHAT to write and WHY
- User writes the actual code
- AI reviews and suggests improvements
- Never write full code for the user
- Give step-by-step instructions with explanations
